# RepoLens — Technical Skills

## Purpose
Technical knowledge and stack required to build RepoLens as a CLI-first local AI engineering agent.

## Tier 1 — Core
- Python, typing, async programming, pytest
- FastAPI, Pydantic, SQLAlchemy
- CLI development and terminal UX
- File-system APIs and subprocess management
- Git and Git diff
- LangGraph and agent loops
- Tool calling and structured LLM output
- Ollama and local LLM inference
- Event-driven architecture
- Permissions and secure command execution

## Tier 2 — Implementation
- AST parsing and symbol extraction
- Import/dependency graphs
- Static analysis
- RAG, embeddings, semantic retrieval
- PostgreSQL and migrations
- Background workers and queues
- Docker and Docker Compose
- GitHub API, webhooks, PRs, Actions
- Structured logging, metrics and tracing

## Tier 3 — Later
- Advanced distributed systems
- Kubernetes
- Advanced model routing
- Multi-machine agent execution
- Cloud deployment

## AI / Agent Skills
- Observe → Plan → Act → Observe loops
- Context management
- Agent state
- Planning
- Memory
- Tool orchestration
- Retry/recovery
- Permission policies

## Code Intelligence
- AST
- Symbols
- Imports
- Dependency graphs
- Git history/diff
- Static analysis
- Code search
- Embeddings
- RAG

## Security
- Secrets detection
- Authentication/authorization
- Least privilege
- Sandboxing
- Process isolation
- Network restrictions
- Prompt injection
- Untrusted repository handling

## Core Stack
Python • FastAPI • LangGraph • Ollama • PostgreSQL • React • TypeScript • Docker • Git • GitHub

## Learning Principle
Learn each system-design concept by implementing the corresponding RepoLens component, rather than studying only interview theory.
